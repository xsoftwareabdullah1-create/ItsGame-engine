# MobileEngine
A Unity-like game engine and editor that runs on Android phones. Written in C# (.NET 8).

## Roadmap
- [x] Step 1: GL surface + APK build
- [x] Orbit camera, touch, ECS scene, 3D renderer, hierarchy + inspector, play mode, physics, save/load
- [ ] Next: move/rotate/scale gizmos, asset import (glTF, textures), Lua/C# scripting, audio, export APK
